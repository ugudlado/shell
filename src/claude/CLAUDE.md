# Global Development Guidelines

Read `spec/project.yaml` for all project context — vision, architecture, tech stack, quality bars, rules, gotchas, and learnings.

## Temporary Files

Save screenshots and other temporary files to the project's `.tmp/` folder (e.g., `<project-root>/.tmp/`), not to system temp directories. Create `.tmp/` if it doesn't exist. Ensure `.tmp/` is in `.gitignore`.
